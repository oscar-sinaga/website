🔐 Izin menyimpan

GitHub Pages tidak memiliki backend untuk menulis file. Karena itu, perlu fine-grained GitHub token milikmu dengan akses hanya ke repository oscar-sinaga/website.

Token hanya dipakai saat menyimpan. Tidak ditanam di source code, tidak disimpan di localStorage/cookie, dan dikosongkan dari kolom setelah percobaan penyimpanan.

Buat fine-grained token di GitHub ↗
  1. Resource owner: oscar-sinaga
  2. Repository access: Only select repositories → website
  3. Permissions → Contents: Read and write
  4. Expiration: pilih yang pendek, misalnya 7 hari
  5. Salin token dan tempel ke kolom ini (jangan pernah kirim token di chat).

Gunakan hanya pada perangkat dan browser yang kamu percayai. Token memberi izin mengubah file repository sesuai cakupannya.

Bagaimana penyimpanannya?

1. Browser memuat file terbaru menggunakan GitHub API.
2. Kamu mengubah teks.
3. Klik Simpan dengan token pribadi.
4. GitHub mencatat commit baru dan Pages memperbarui website.

Jika file berubah saat kamu sedang mengedit, editor tidak akan menimpa perubahan tersebut secara diam-diam.
